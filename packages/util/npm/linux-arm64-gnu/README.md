# @e2e-dev/util-linux-arm64-gnu

The Linux arm64 (glibc) build of the native addon of
[`@e2e-dev/util`](https://www.npmjs.com/package/@e2e-dev/util), the image
work of `e2e`. npm installs it with `@e2e-dev/util` on arm64 Linux with glibc 2.35 or later;
nothing imports it directly.
