# @e2e-dev/util-linux-x64-gnu

The Linux x64 (glibc) build of the native addon of
[`@e2e-dev/util`](https://www.npmjs.com/package/@e2e-dev/util), the image
work of `e2e`. npm installs it with `@e2e-dev/util` on x64 Linux with glibc 2.28 or later;
nothing imports it directly.
