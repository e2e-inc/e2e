Cada exemplo é um app de saudação independente, com três testes de localizador
e dois testes de agente. Um teste de agente obtém uma saudação para um nome; o
outro verifica o erro de nome vazio. Cada exemplo instala os pacotes
publicados do e2e a partir do npm.

## Rode um exemplo

Siga o README do projeto para instalar, fazer o build e rodar o exemplo. A
configuração e os testes ficam ao lado do app, em uma pasta `e2e/` nos
projetos nativos, Flutter e .NET MAUI.

Os testes de localizador não precisam de modelo. Os testes de agente usam o
Vercel AI Gateway e são pulados a menos que `AI_GATEWAY_API_KEY` esteja
definida.

Para começar um novo app Next.js a partir do exemplo com `create-next-app`,
veja [Next.js](/frameworks/nextjs#start-a-new-app).
