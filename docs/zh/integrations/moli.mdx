[Moli](https://github.com/lexmount/moli) 是支持 Chrome DevTools Protocol 的开源浏览器。`@e2e-dev/moli` 中的 `moli()` 会为每个工作进程槽位启动一个本地浏览器，并在运行结束时停止它。

<Note>
网页端引擎可以在 Moli 中打开并读取页面。对元素的操作会失败，截图也会失败。参阅[不支持的功能](#what-does-not-work)。
</Note>

## 启动 Moli 测试目标

安装 [Moli 二进制文件](https://github.com/lexmount/moli#direct-installation)和以下包：

<CodeGroup>
```bash npm
npm install --save-dev e2e @e2e-dev/web @e2e-dev/moli
```

```bash pnpm
pnpm add -D e2e @e2e-dev/web @e2e-dev/moli
```

```bash bun
bun add -d e2e @e2e-dev/web @e2e-dev/moli
```
</CodeGroup>

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { moli } from '@e2e-dev/moli';

export default {
  targets: [
    {
      name: 'moli',
      engine: web({ browser: moli() }),
      app: { url: 'http://localhost:3000' },
    },
  ],
} satisfies E2EConfig;
```

使用 [`e2e run`](/reference/cli#e2e-run) 运行测试。每个工作进程使用独立的 Moli 进程，并占用一个可用的回环端口。如果服务器未在 10 秒内提供 CDP，其租约就会失败。

## 配置浏览器

| 选项 | 默认值 | 含义 |
| --- | --- | --- |
| `binary` | 依次查找 `MOLI_PATH`、`PATH`、`~/.local/bin/moli` | 可执行文件的路径或名称。在浏览器启动时从本次运行的环境中解析。 |
| `layout` | `true` | 传入 `--layout`，启用按需布局和截图。 |
| `loadResources` | `true` | 传入 `--resource`，获取可选的图片、字体、音频、视频、媒体和文本轨道。 |
| `args` | `[]` | 额外的 `moli serve` 标志。 |

提供方支持工作进程作用域。尚未实现每次尝试独立的租约。

<Accordion title="连接到你自行启动的服务器">
在单独的终端中启动 Moli：

```bash
moli serve --host 127.0.0.1 --port 19222 --layout --resource
```

使用网页端引擎的 `connect` 选项进行连接。运行结束后，该服务器会继续运行：

```ts
web({ connect: { cdpEndpoint: () => process.env.MOLI_CDP_URL?.trim() || 'http://127.0.0.1:19222' } })
```
</Accordion>

## 不支持的功能

打开页面、查询、断言、Cookie 和初始化脚本都可用。在 Moli 1.1.25 上，无论使用提供方还是 `connect`，以下功能都会失败：

| 功能 | 实际行为 | 原因 |
| ------- | ------------ | --- |
| 对元素的操作：`tap`、`fill`、`check`、`hover`、`swipe`、`setInputFiles` | 操作会在其 [`actionTimeout`](/reference/config#actiontimeout) 结束时失败，错误为 `ACTION_FAILED` 或 `LOCATOR_NOT_FOUND`。 | Moli 不会以引擎能读取的方式标识元素。 |
| 截图 | 截图时抛出 `ENGINE_FAILURE`。 | Moli 没有 `document.getAnimations`。 |
| 框架内的查询 | 查询以 `LOCATOR_NOT_FOUND` 失败。 | 引擎在该框架中找不到文档。 |

修复需要 Moli 自身做出改动。请查看其[上游问题](https://github.com/lexmount/moli/issues)，并在 Chromium 测试目标上运行需要操作页面的测试。
