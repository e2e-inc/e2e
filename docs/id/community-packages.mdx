Paket komunitas memperluas e2e dengan tool, engine, dan reporter. Pemeliharaan dan dukungannya ada pada maintainer masing-masing, bukan tim inti e2e. Tercantumnya sebuah paket bukan berarti direkomendasikan.

Periksa dokumentasi setiap paket untuk mengetahui versi e2e yang didukung dan persyaratan penyiapannya. Versi di bawah ini mencatat paket terbitan yang diperiksa saat setiap entri ditambahkan, bukan hasil uji kompatibilitas oleh tim e2e.

## Temukan paket

### `e2e-cige`

Menjalankan test case [CIGE](https://www.amazon.science/publications/cige-an-agentic-ai-test-case-standard) dalam bentuk JSON melalui `agent.act` dan `agent.assert`. Menyertakan ringkasan eksekusi dan pemeriksaan untuk agent yang memperbaiki tes yang gagal.

Maintainer: [Vivek Krishna](https://github.com/vivekkrishna). Versi `0.1.0` mendeklarasikan `e2e >=0.21.0 <1`.

[npm](https://www.npmjs.com/package/e2e-cige) · [Repositori dan penyiapan](https://github.com/vivekkrishna/cige)

### `@appduct/e2e`

Memanggil tool Appduct milik aplikasi dari fixture tes atau langkah agent melalui MCP. Mendukung target web, simulator iOS, dan emulator Android.

Maintainer: [Callstack](https://github.com/callstackincubator/appduct). Versi `0.16.0` mendeklarasikan `e2e >=0.21.0 <1` dan `ai ^7.0.0`.

[npm](https://www.npmjs.com/package/@appduct/e2e) · [Repositori dan penyiapan](https://github.com/callstackincubator/appduct/tree/main/packages/e2e)

### `@mobai-app/e2e`

Menambahkan engine perangkat MobAI dan reporter dasbor untuk perangkat iOS dan Android fisik, simulator, emulator, dan device farm.

Maintainer: [MobAI](https://github.com/MobAI-App). Versi `0.1.3` mendeklarasikan `e2e >=0.19.0 <1`.

[npm](https://www.npmjs.com/package/@mobai-app/e2e) · [Repositori dan penyiapan](https://github.com/MobAI-App/mobai-e2e)

### `@testdino/e2e`

Melaporkan test case, percobaan ulang, langkah, error, output konsol, screenshot, dan video ke TestDino.

Maintainer: [TestDino](https://testdino.com). Versi `1.1.0` mendeklarasikan `e2e >=0.16.0 <1`. Perintah pemilihan dan eksekusi ulang memerlukan e2e `0.19.0` atau yang lebih baru.

[npm](https://www.npmjs.com/package/@testdino/e2e) · [Dokumentasi](https://docs.testdino.com/cli/testdino-e2e)

### `@testomatio/reporter`

Mengirim hasil e2e ke Testomat.io melalui adapter `@testomatio/reporter/e2e`.

Maintainer: [Testomat.io](https://github.com/testomatio). Versi `2.23.0` menyertakan adapter tersebut. Contohnya memakai `e2e ^0.21.0`; paket ini tidak mendeklarasikan rentang peer e2e.

[npm](https://www.npmjs.com/package/@testomatio/reporter) · [Repositori dan contoh](https://github.com/testomatio/reporter/tree/2.x/example/e2e)

### `@waitcher/cli`

Menjalankan tes `*.e2e.ts` dari repositori Anda sesuai jadwal sebagai monitor Waitcher, dan mengirim peringatan saat eksekusi gagal. Tes browser memakai `@e2e-dev/web` dengan Chromium; tes API memakai `e2e`. Waitcher adalah layanan komersial terkelola dengan paket gratis, dan CLI-nya berlisensi proprietary.

Maintainer: [Sławomir Radzymiński](https://github.com/slawekradzyminski). Versi `0.2.28`, terbit 19 November 2026, menjalankan tes dengan `e2e 0.24.0` dan `@e2e-dev/web 0.16.1`.

[npm](https://www.npmjs.com/package/@waitcher/cli) · [Dokumentasi dan contoh](https://waitcher.dev/docs/repository-workflow)

## Temukan integrasi terkait

Tim e2e memelihara [integrasi browser dan perangkat cloud](/integrations), [reporter GitHub](/github), dan [reporter bawaan](/reference/reporters).

Untuk rangkaian tes aplikasi dan contoh provider, jelajahi [contoh komunitas dan mitra](https://e2e.com/examples). Contohnya mencakup [contoh alur aplikasi dari Limrun](https://github.com/limrun-inc/testerarmy-e2e-limrun) dan [contoh provider browser dari Notte](https://github.com/nottelabs/notte/tree/main/examples/e2e).

## Tambahkan paket Anda

Buka pull request untuk [mengedit halaman ini](https://github.com/e2e-inc/e2e/edit/main/docs/community-packages.mdx). Sertakan:

- Nama paket, tautan ke paket yang sudah terbit, serta repositori atau dokumentasinya.
- Deskripsi singkat tentang cara paket terintegrasi dengan e2e, beserta contoh kode sumber atau penggunaan.
- Maintainer, platform yang didukung, dan persyaratan kompatibilitas e2e.
- Versi dan tanggal terbit yang diperiksa untuk penambahan ini.

Tulis deskripsi secara faktual. Laporkan masalah paket kepada maintainer-nya. Kirim contoh aplikasi melalui [panduan kontribusi contoh](https://github.com/e2e-inc/e2e/blob/main/examples/CONTRIBUTING.md).
